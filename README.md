# Drawing Workbook Generator

A small Streamlit app for turning one or more reference images into printable black-and-white drawing-practice workbooks.

The workbook sequence is designed around a repeatable process:

1. Blind contour - no grid
2. Regular contour - no grid
3. SAM / mapping - fine, medium, coarse, then center-cross scaffolds
4. Upside-down drawing - scaffold retained
5. Negative space - scaffold retained
6. 3-value study - optional
7. 5-value study - optional
8. Progressive focus - optional; one evolving drawing from blurred to sharp
9. Integrated study - optional; center-cross support

For supported exercises, the app can create compact same-page versions and larger practice pages. Drawing boxes follow the uploaded image's aspect ratio instead of forcing everything into a fixed frame.

## What changed in this version

- PDF is generated **directly in Python** with ReportLab.
- LibreOffice is **not required**.
- DOCX is no longer generated by default.
- The image uploader is designed as a large **drag-and-drop area** and supports multiple images.
- Each uploaded image has its own exercise checkboxes.

## Files

- `app.py` - Streamlit user interface
- `workbook_generator_backend.py` - image processing + direct PDF workbook generation
- `example_build.py` - small programmatic example
- `requirements.txt` - Python dependencies

## Windows setup

### 1. Clone this repository

Use GitHub Desktop, as usual.

### 2. Open a command window in the repository folder

In File Explorer, open the repo folder, click the address bar, type `cmd`, and press Enter.

### 3. Install/update dependencies

```bat
python -m pip install -r requirements.txt
```

### 4. Run the app

```bat
python -m streamlit run app.py
```

A browser window will open.

## Using the app

1. Drag one or more reference images into the upload box.
2. Choose the exercises for each image.
3. Choose compact pages, large-study pages, or both.
4. Choose scaffold levels.
5. Click **Generate PDF workbook**.
6. Download the finished PDF.

## Current limitation

Crop approval is not interactive yet. The backend currently applies a conservative automatic crop and then uses that crop consistently throughout the workbook.
